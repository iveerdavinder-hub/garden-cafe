# Garden Cafe Website

A responsive, single-page website for Garden Cafe, Sarabha Nagar, Ludhiana.

## Run locally
Open `index.html` in a browser. No build step is required.

## Deploy to Vercel
1. Create a new GitHub repository and upload `index.html`.
2. Import the repository in Vercel.
3. Select **Other** as the framework preset (or let Vercel detect a static site).
4. Deploy. No build command or environment variables are required.

## Included interactions
- Responsive navigation and mobile menu
- Scroll reveal animations and cinematic hero
- Menu category filters
- Click-to-expand gallery lightbox
- Google Maps embed and directions links
- Reservation form that opens WhatsApp with a pre-filled message
